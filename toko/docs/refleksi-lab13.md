# Refleksi Lab 13

Di dalam container, `localhost` berarti container itu sendiri, sehingga order-service yang memanggil `localhost:3000` tidak akan menemukan product-service dan harus memakai nama service `http://product-service:3000`. Nama itu diterjemahkan menjadi alamat IP container oleh server DNS internal Docker pada jaringan Compose, yaitu contoh nyata service discovery. Container bersifat sementara dan data produk, stok, serta pesanan hanya ada di memori proses, sehingga `docker compose down` lalu `up` mengembalikan semuanya ke data awal; sistem nyata membutuhkan database terkelola seperti Neon atau volume agar data bertahan di luar siklus hidup container. Menaruh kredensial bawaan seperti guest/guest di `docker-compose.yml` yang masuk repository berarti siapa pun yang dapat membaca repository (termasuk riwayat git-nya) mengetahui kata sandi itu, dan nilai tersebut mudah terbawa ke produksi sehingga broker bisa diakses orang lain. Di produksi, rahasia sebaiknya diberikan lewat environment variable atau secret manager milik platform (misalnya Docker/Compose secrets, GitHub Actions secrets, atau dashboard hosting) dengan nilai acak yang berbeda per lingkungan, bukan ditulis di berkas yang di-commit.
